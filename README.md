# GlovesOn: Jobsite Companion

Mobile-friendly concrete calculator and jobsite toolkit with a big-button UI built for gloves.

## What it does

A mobile-first progressive web app for construction crews. Everything runs offline with no account and no server, since all data stays on the device. It bundles a concrete and materials volume calculator (slab, footing, wall, curb, approach, round column, with truck loads and waste percent), a field unit converter, a daily time log with overtime rules, and freeform jobsite notes.

## Tech stack

- Vanilla HTML, CSS, JavaScript (no framework, no build step)
- Progressive Web App (installable, works offline)
- localStorage for all data persistence (no backend)
